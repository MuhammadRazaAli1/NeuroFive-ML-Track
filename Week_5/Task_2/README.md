# 🚢 Titanic Survival Predictor - Live Web App

This project transforms a Machine Learning model into a fully functional, interactive web application using **Streamlit**. 

## 🚀 Live Demo
**Try the app here:** https://titanic-survivor-predictor.streamlit.app/

## 🛠️ Tech Stack
- **Model:** Random Forest Classifier (Trained with Scikit-Learn)
- **Web Framework:** Streamlit
- **Deployment:** Streamlit Community Cloud

## 💡 How it Works
The app takes 4 key inputs from the user (Passenger Class, Gender, Age, and Ticket Fare), processes them to match the training data format, and passes them to the pre-trained `.joblib` model to instantly predict whether the passenger would have survived the Titanic disaster.
